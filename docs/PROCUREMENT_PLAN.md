# Procurement Plan

## Principle

The build should start from the best verified source deal, but the locked drivetrain architecture remains Route A unless materially better evidence changes the durability case.

## Priority sourcing order

1. Hellcat/Redeye 6.2 engine package
2. Max-effort NAG1 / core strategy
3. Converter
4. Built NV146
5. Rear Wavetrac + axle package
6. Transmission cooling
7. Driveshafts after final installed measurements
8. Mounts / bushings
9. Tuning / commissioning

## Buy rules

- Prefer complete, verified assemblies over incomplete cheap parts that trigger hidden hardware costs.
- Seller quality, donor VIN, mileage proof, compression/leak-down evidence, and running history matter more than headline price.
- Do not buy driveshafts before final installed geometry is frozen.
- Do not buy custom front CVs before a demonstrated need exists.
- Do not pay premium race-part pricing for components outside the 850-WHP duty cycle.

## Quote strategy

For every major component obtain at least two comparable quotes using the same requested hardware specification rather than vendor stage names.

### NAG1 request

Quote a 4WD NAG1 with:
- 300M input shaft
- upgraded/new output shaft as required
- increased K1/K2/K3/B2 clutch capacity
- performance frictions/steels
- HD F1/F2 sprags
- tested/calibrated valve body
- inspected/remanufactured pump
- planetary inspection
- new conductor plate / seals / filter
- compatibility with preserved shift torque management

### NV146 request

Quote:
- HD chain/bearings where applicable
- upgraded clutch pack / steels
- pump rebuild/inspection
- complete seals/bearings service
- actuator/control inspection
- intended use: 800–850 WHP street WK1 with occasional controlled launches

## Sourcing stop rule

Do not buy a part merely because it is available. Buy when the exact part closes a defined build requirement at or below the maximum sensible price in `data/parts-budget.csv`.
