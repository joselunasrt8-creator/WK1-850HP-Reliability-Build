# Research Status

## Closed / strong conclusions

- Route A is the current primary architecture for a reliability-first ~850-WHP WK1.
- The NAG1/NV146 path preserves substantially more native WK1 geometry and controls than an 8HP95/Trackhawk-AWD transplant.
- Peak horsepower alone is not the main durability threat; launch shock, tire grip, torque intervention, and heat are equally important.
- A max-effort NAG1, proactively built NV146, upgraded driveshafts, HD rear axles, rear LSD, and strict torque management form the current defensible reliability package.
- The front differential and front CV architecture should be retained initially unless inspection or real use demonstrates a need to replace them.

## Current verdict

**YELLOW — build with operating limits.**

The expected reliable envelope is approximately 800–850 WHP with controlled launches and preserved WOT shift torque reduction.

## Evidence hierarchy

Use evidence in this order:

1. completed vehicles with documented performance and service history
2. builder technical documentation
3. owner/build threads
4. manufacturer claims
5. forum speculation only as a lead

## Open questions

1. Which vendor provides the best value for the required max-effort NAG1 hardware specification?
2. Which NV146 builder provides the strongest documented upgrade package and service support?
3. What converter stall / lockup strategy best balances street manners, heat, and launch durability with the selected 6.2 combination?
4. Which driveshaft vendor should own final joint, tube, critical-speed, and balance specification?
5. What exact rear axle / hub package gives the best durability-to-cost ratio?
6. What transmission-temperature limits does the selected builder require for warranty / service life?
7. What torque ceilings should be finalized in first and second gear after logged testing?
8. Does the stock front differential remain reliable under the final tire and launch strategy?
9. Which suspension / bushing changes reduce wheel hop without making the Jeep harsh?
