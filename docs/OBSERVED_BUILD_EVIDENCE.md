# Observed Build Evidence

This document records owner/build evidence separately from the project's durability recommendations. An observed configuration proves only what the source actually documents; it does not automatically establish an 850-WHP reliability rating.

## JHGarage — Hellcat 6.2 into WK1

### Source type
Owner/builder comments accompanying video documentation, preserved from screenshots supplied to the project.

### Observed / owner-reported configuration

The builder reports:

- complete Hellcat engine with accessories
- stock 6.1 WK1 engine mounts
- stock WK1 harness and ECU
- Hellcat MAP sensor
- VVT lockout
- 6.2 crank tone ring changed to the older 6.1-style tone ring
- stock-internal NAG1
- Dings 200% valve body
- dual Fore fuel pumps
- external fuel-pressure regulator
- -8AN fuel feed and return lines
- SmoothBoost supercharger controller

The builder also states that the power-steering reservoir remains present next to the throttle body as part of the complete Hellcat accessory arrangement.

### What this evidence supports

This is useful integration evidence that a Hellcat 6.2 can be installed while retaining substantial WK1 architecture, including the stock 6.1 mounts and stock WK1 ECU/harness strategy, with crank-trigger and VVT changes used to make the later engine compatible with the earlier control architecture.

It also documents at least one running swap using a stock-internal NAG1 with a valve-body modification.

### What this evidence does NOT establish

The supplied evidence does not establish:

- measured wheel horsepower or torque
- boost level
- vehicle weight
- NV146 configuration
- driveshaft, differential, axle, or CV configuration
- NAG1 converter specification
- transmission temperatures
- launch strategy
- quarter-mile/60-foot performance
- mileage or pass count
- long-term durability
- reliability at 800–850 WHP

Therefore this build must not be used as evidence that a stock-internal NAG1 or stock downstream driveline is reliable at the project's 800–850 WHP target.

## Project implication

This evidence strengthens the case for investigating a native-integration path before specifying unnecessary conversion hardware:

**Hellcat 6.2 → stock 6.1 mounting geometry → WK1 ECU/harness strategy → compatible crank trigger/VVT configuration → NAG1/NV146 architecture**

The durability specification remains a separate engineering question. For the project target, the current recommendation remains a strengthened NAG1, proactively built NV146, controlled torque delivery, upgraded shafts/rear axles, and condition-based treatment of the remaining native driveline.

## Evidence discipline

Future build observations should be recorded with the same separation:

1. **Observed fact** — explicitly shown or stated by the builder.
2. **Supported conclusion** — what that observation reasonably demonstrates.
3. **Unknown** — information not supplied by the source.
4. **Project implication** — how the evidence changes or strengthens the current specification.

A running vehicle is integration evidence. A dyno number is power evidence. A pass is performance evidence. Documented repeated use or mileage is durability evidence. These categories should not be treated as interchangeable.
